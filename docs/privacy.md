# 資料處理說明

本文件描述目前實作，不代表已完成合規審查或安全認證。

## 處理的資料

| 位置／服務 | 資料與用途 |
| --- | --- |
| 瀏覽器 localStorage | Email，供下次開啟時識別帳號；登出會移除 |
| 瀏覽器 sessionStorage | 進行中的 job ID，供同一分頁接續查詢 |
| Cloudflare Workers / D1 | Email、Threads URL／正文／作者、AI 結果、監控門檻、價格點、寄信與錯誤紀錄 |
| OpenAI | 貼文正文用於意圖分析；商品名稱、關鍵字與 item key 用於估價；程式未刻意附上帳號 Email，但正文自身可能包含個資 |
| Apify | 搜尋關鍵字與蝦皮抓取設定 |
| Resend | 收件 Email、商品與價格門檻等信件內容 |
| 第三方商品圖片主機 | 瀏覽器直接請求商品圖片，主機可收到 IP 等網路資訊 |

Threads 內容由伺服器抓取。第三方服務可能另有自己的紀錄與保留規則，本專案未驗證其帳戶設定。

## 已知限制

- Email 未驗證所有權；API 不具備完整的跨帳號授權保護，詳見 [安全說明](../SECURITY.md)。
- Email 目前出現在部分 GET query，可能進入服務存取紀錄；localStorage 可由同來源 JavaScript 讀取。
- 上游錯誤原文只做密鑰遮罩，仍可能包含個資或內部資訊。診斷信件回應會保存在資料庫。
- 介面只讀取近 180 天價格點，**不是 180 天自動刪除政策**。目前沒有帳號整體刪除或資料到期清理流程。
- 刪除監控不會連帶刪除所有歷史 jobs、寄信紀錄或第三方紀錄；登出只清除瀏覽器 Email。

正式營運前需完成身分驗證、最小化錯誤與日誌、訂定資料保留期限，以及提供整體刪除與第三方資料處理說明。
